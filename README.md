## 🚀 How to Host on GitHub Pages (Free Live Link)

Follow these 4 simple steps to get a free live URL (`https://your-username.github.io/beFit/`):

### Step 1: Initialize Git and Commit
Open PowerShell or Terminal inside this `c:\xampp\htdocs\beFit` folder and run:
```bash
git init
git add .
git commit -m "Initial commit of Be Fit Raipur luxury website"
```

### Step 2: Create a New Repository on GitHub
1. Go to [github.com/new](https://github.com/new).
2. Repository name: `beFit` (or `befit-raipur`).
3. Make it **Public**.
4. Click **Create repository**.

### Step 3: Link & Push
Run the commands GitHub gives you:
```bash
git branch -M main
git remote add origin https://github.com/<your-username>/beFit.git
git push -u origin main
```

### Step 4: Turn On GitHub Pages
1. On your GitHub repo page, click **Settings** (gear icon on the right).
2. On the left sidebar, click **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Within 1-2 minutes, GitHub will give you your live URL:
   `https://<your-username>.github.io/beFit/`
